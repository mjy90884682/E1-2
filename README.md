# Python 퀴즈 게임

## 프로젝트 개요

터미널에서 문제를 풀고 새로운 문제를 등록할 수 있는 콘솔 퀴즈 게임입니다. 등록한 문제와 최고 점수는 프로젝트 루트의 `state.json`에 저장되므로 프로그램을 다시 실행해도 유지됩니다.

## 퀴즈 주제와 선정 이유

기본 퀴즈의 주제는 Python 기초 문법입니다. 프로젝트에서 사용하는 함수, 리스트, 조건문, 딕셔너리와 JSON을 문제로 다시 확인할 수 있고, 학습한 내용을 프로그램의 소재로 직접 활용하기에 적합해서 선정했습니다.

## 실행 방법

Python 3.10 이상이 필요하며 외부 라이브러리는 사용하지 않습니다.

```bash
python3 main.py
```

테스트는 Python 표준 라이브러리인 `unittest`로 실행합니다.

```bash
python3 -m unittest discover -s tests -v
```

## 기능 목록

- 기본 문제와 사용자가 추가한 문제 풀기
- 문제, 선택지 4개와 정답 번호를 입력해 퀴즈 추가
- 등록된 퀴즈 목록 확인
- 정답률과 정답 개수에 따른 최고 점수 확인
- 잘못된 숫자와 빈 입력에 대한 재입력 안내
- 손상된 상태 파일 보존 및 초기 상태 복구
- 입력 중단 시 안전한 종료와 미저장 데이터 저장 재시도

## 파일 구조

```text
.
├── data/
│   └── initial_state.json  # 최초 실행과 손상 복구에 사용하는 상태
├── tests/
│   └── test_quiz_game.py   # 모델, 게임과 저장 기능 테스트
├── console_ui.py           # 터미널 입력과 출력
├── game.py                 # 게임 기능과 상태 변경
├── main.py                 # 프로그램 조립과 메뉴 흐름
├── models.py               # 퀴즈, 세션, 점수와 상태 모델
└── storage.py              # JSON 파일 읽기, 쓰기와 손상 파일 보존
```

## 데이터 파일

`data/initial_state.json`은 기본 퀴즈 5개가 들어 있는 읽기 전용 초기 상태입니다. 프로젝트 루트에 `state.json`이 없거나 기존 파일이 손상된 경우 이 데이터로 시작합니다.

퀴즈를 추가하거나 최고 점수가 갱신되면 기본 문제를 포함한 현재 전체 상태를 UTF-8 형식의 `state.json`에 저장합니다. 손상된 파일은 덮어쓰지 않고 `state.json.broken`, `state.json.broken.1`과 같은 이름으로 보존합니다.

```json
{
  "quizzes": [
    {
      "question": "Python에서 함수를 정의할 때 사용하는 키워드는?",
      "choices": ["func", "def", "function", "lambda"],
      "answer": 2
    }
  ],
  "best_score": {
    "correct": 4,
    "total": 5
  }
}
```

- `quizzes`: 문제, 선택지 4개와 1부터 4 사이의 정답 번호를 가진 퀴즈 목록
- `best_score`: 최고 기록의 정답 개수와 전체 문제 수. 아직 기록이 없으면 `null`

정답률(`percentage`)은 중복 저장하지 않고 `correct`와 `total`로부터 계산합니다. 최고 점수는 정답률을 먼저 비교하고, 정답률이 같으면 더 많은 문제를 맞힌 기록을 우선합니다.
